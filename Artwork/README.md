# QuietFrames artwork

`Moonlit-Mystic-Bronze.png` is the original supplied 1254 x 1254 artwork.

Each installable addon includes the same `Media/QuietFrames.tga`: an uncompressed
32-bit RGBA TGA, resized to 128 x 128 with Lanczos resampling. The original
composition and background are preserved, without cropping or added text.

The existing 26 x 26 minimap button displays the complete texture with coordinates
`(0, 1, 0, 1)`. Its appearance does not change with mode. Both packages carry their
own copy so neither version depends on the other being installed.
